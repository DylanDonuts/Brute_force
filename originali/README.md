# Sorgenti originali ricevuti

`algoritmo.py` e `test.py` in questa cartella sono copie byte per byte degli allegati iniziali. Documentano il punto di partenza, con i suoi limiti: seed incompatibile con Python recente, ricerca incompleta e test fragili.

Non sono la versione da eseguire. Dalla radice del progetto usa `python algoritmo.py` e `python -m unittest discover -s tests -v` (su Windows anche `py`, su Linux/macOS normalmente `python3`).

La prima revisione annotata è conservata nel commit precedente alla correzione. `docs/storia/` descrive quella versione, mentre la documentazione principale riguarda la v2.
